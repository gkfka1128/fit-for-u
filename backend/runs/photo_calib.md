## 4. 결론

- **사진만으로는 찍기 수준** (순위상관 −0.05~0.09, 3분위 32~36%, 카파 ≈ 0). 특징 2,608명 · 40여 개 중 어떤 것도 |0.10| 을 넘지 못함.
- **사진을 더해도 키·몸무게만 쓴 것보다 나아지지 않음** (남 0.19 → 0.11, 여 0.29 → 0.29). 9/18 실루엣·3D 메시 실험과 같은 결론.
- 키·몸무게도 약함 (3분위 42~43%) — 상·하체 형태는 BMI 와 거의 독립이라 어떤 자동 추정도 잘 못 잡는다 → 형태는 **사용자 1문항**이 여전히 가장 현실적인 입력.
- 웹 추출기의 '가슴' 폭은 어깨 관절 폭의 1.6배 — 위팔이 포함됨. 팔꿈치·손목만 보는 지금의 팔 겹침 검사로는 못 잡는다.
- ⚠ 한계: 데이터는 옷 입고 팔 내린 착용 사진, 측면 없음. 가이드대로(붙는 옷·팔 벌림·측면 추가) 찍은 사진에서는 다를 수 있으므로 → 팀원·지인 30명 통제 촬영 + 줄자 실측으로 따로 재야 결론이 난다.
