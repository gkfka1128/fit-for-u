# 사진 체형 분석 검증 — 웹 경로(정면 1장 → three_conditional 군집 → 체형) vs 실측

AI Hub 의류 통합 데이터 착용 사진, 성별당 300명 (seed 0, 사람당 얇은 옷 정면 컷 1장), 1분.
정답 = 실측 3분위(상·하체) · BMI(체격). 군집→체형 연결은 `body_cluster_bridge.CLUSTER_BODY` (임시). 찍기 기준 = 3분위라 상·하체 33%.

| | 사진에서 잰 가슴/엉덩이 너비비 U (중앙값, 25~75%) | 모델 군집 중심 U (Size Korea 실측 너비로 학습) |
|---|---|---|
| 여 | 1.38 (1.25 ~ 1.48) | 0.80 · 0.83 · 0.88 |
| 남 | 1.47 (1.35 ~ 1.58) | 0.93 · 0.95 · 1.02 |

- 사진의 U 가 모델이 아는 범위보다 1.5배쯤 커서, 거의 모든 사진이 U 가 가장 큰 군집 하나로 몰린다 (여 100% 군집 1, 남 75% 군집 1).
  모델 쪽에도 `input_domain = uncalibrated_camera_proxy`, `photo_validated = false` 로 적혀 있는 바로 그 문제.
- 눈금만 다르면 보정(사진 → 실측 비율 변환)으로 고칠 수 있지만, §4 순위상관이 0.04~0.08 이라 **순서조차 안 맞는다** → 보정만으로는 안 됨.
- 남성 체격 일치율 63~71% 는 실측에서 통통(BMI ≥ 23)이 60% 라서 생긴 수치 — 군집 1(균형·통통)로 몰린 결과가 다수 클래스와 겹친 것.
